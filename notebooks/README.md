# Notebooks

- `trained_networks/`: learned-network experiments.
- `constructed_networks/`: closed-form finite-group RNN experiments.

For constructed notebooks, edit the paired percent-format `.py` file; the
`.ipynb` file is its notebook counterpart. Keep the two synchronized, but do
not maintain two independent versions.

`constructed_networks/figure_7.py` and `figure_8.py` build their respective
SVGs. Each `# %%` section corresponds to setup, one panel, or final assembly.
